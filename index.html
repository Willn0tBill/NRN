01 — The Network

Built to grow beyond SGN.

Softbear Games Network became New Republic Network so the project could expand beyond a single studio. NRN now serves as the umbrella for game coverage, community awards, and news across multiple gaming communities.

The name also aligns the network with the broader New Republic identity while keeping the original SGN mission recognizable.
