GitHub-only publishing

How publishing works

GitHub Pages cannot safely keep an administrator password or GitHub write token in browser JavaScript. This portal therefore prepares your changes and sends you to GitHub's authenticated editor to commit them. GitHub remains the real security boundary.

NRNN: Generate the article here → Copy → Open news.js → paste the new object inside window.NRNN_ARTICLES → Commit changes. GitHub Pages redeploys the site.
NRNA: Use the NRNA panel to open the website source when you need to change forms, categories, dates, or award-cycle text.
